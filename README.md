# AirLink · 隔空快传

> 两台设备之间，文件直达。
>
> 一个 Windows 单文件 exe、一个 Android apk，双击即用。不需要账号，不需要服务器，不经过任何第三方。

## 这是什么

同一个 Wi-Fi 下，两台设备打开软件就能互相看见，点一下就传；不在同一个网络时，只要有公网 IPv6，填一个地址加 6 位配对码就能直连。

数据**不经过任何服务器**，你的文件只在两台设备之间跑。

| 能力 | 说明 |
| --- | --- |
| 局域网自动发现 | UDP 广播，打开即出现在对方列表里 |
| 扫码连接 | 二维码里带地址、端口和配对码，扫一下就填好 |
| 广域网直连 | IPv6 原生直连，无需端口映射；没有 IPv6 时退回 UPnP 自动映射 |
| 双向文件浏览 | 电脑看手机、手机看电脑，像翻自己的文件夹 |
| 传输记录 | 一开始传就进记录，双端按 id 同步状态 |
| 熄屏保活 | 前台服务 + 唤醒锁 + Wi-Fi 锁，锁屏不掉线 |

## 快速开始

### 电脑端

1. 打开 `完整版应用/`，下载 **`Windows-AirLink.exe`**
2. 双击运行（**无需安装，无需运行库，无 DLL 依赖**）
3. Windows 提示防火墙时点「允许访问」
4. 左侧能看到本机所有网卡的地址，「附近设备」会自动刷新

> 需要从外网连进来时，要在 Windows 防火墙放行 **TCP 45678** 入站；只在局域网内用则不需要。

### 手机端

1. 打开 `完整版应用/`，下载 **`Android-AirLink.apk`** 安装（minSdk 21，Android 5.0 及以上）
2. **首次安装务必把权限全部打开**——尤其是「所有文件访问」「相机」「后台弹出界面」「自启动」
3. vivo / iQOO 等机型还要在「电池 → 后台耗电管理」里改成 **允许后台高耗电**，否则熄屏后电脑读不到手机文件

逐项设置说明见 `完整版应用/⭐️使用说明(一定要先看这个！！！).txt`。

## 使用指南

### 场景一：同一个 Wi-Fi

1. 两端都打开软件，几秒后互相出现在「附近设备」
2. 点对方设备 → 建立连接
3. 拖文件到窗口（电脑端）或点「选择文件发送」（手机端）

在手机端点击设备右侧的「已连接」，会直接进入电脑文件界面，能看到 `C:` `D:` 等盘符。

### 场景二：扫码

电脑端首页有一张二维码，手机端点「扫二维码连接」扫它即可，地址和端口自动填好。

> 二维码显示在显示器上会有反光和摩尔纹，扫不上时把手机靠近一点、调亮屏幕，或者直接手输地址。

### 场景三：不在同一个网络（WAN）

**电脑端**

1. 左侧点「WAN 连接」
2. 复制「公网 IPv6」那一行的地址，形如 `[240e:878:55:7142:4fcf:f038:b68:1b37]:45678`（**方括号和端口都要带上**）
3. 记下界面上的 6 位**配对码**

**手机端**

1. 底部点「WAN」
2. 「电脑公网地址」粘贴上面的地址（也可以用微信发给自己再复制）
3. 「配对码」填电脑上显示的 6 位数字，点「连接」

连接成功后自动跳转到电脑文件界面。

> **前提**：手机和电脑都要有公网 IPv6。国内移动/联通/电信的宽带和移动网络基本都支持；部分路由器需要在设置里开启 IPv6。

**反过来也行**：电脑端在「WAN 连接」页下方的「主动连接其它设备」里，填对方的 IPv6 地址和配对码，就能由电脑发起连接。

## 安全说明

把端口开到公网，就必须有一道闸。

| 规则 | 说明 |
| --- | --- |
| 内网免密 | 来源地址在 `10.` / `192.168.` / `172.16-31.` / `127.` 段内，直接放行 |
| 外网要配对码 | 非内网来源必须先出示正确的 6 位配对码，否则任何请求都被拒绝 |
| 有效期 10 分钟 | 校验通过后该地址 10 分钟内免检，不用每次重输 |
| 校验在本地 | 配对码不上传、不经手任何服务器 |

**需要清楚的边界**：配对码是访问控制，不是传输加密。局域网内的链路是明文 TCP，请不要在不信任的网络上传输敏感内容。如果要更严密，可以在此基础上加 TLS。

## 技术架构

两端共用同一套协议定义，逐字节一致（所有整数一律小端）。

| 层 | 端口 | 职责 |
| --- | --- | --- |
| 发现层 | UDP 45679 | 广播探询与应答，仅用于局域网可见 |
| 传输层 | TCP 45678 | `ALFT` 魔数 + 版本 + 类型，**6 字节头部**，其余全是负载 |
| 应用层 | 11 类消息 | 推文件(1) 列目录(2) 取文件(3) 心跳(4) 断开(5) 删除(6) 会话(7) 记录同步(8/9/10) 配对认证(14) |

**双栈监听**：一个 socket 同时服务 IPv4 与 IPv6；IPv4 对端会以 `::ffff:a.b.c.d` 形式出现，取地址时折叠回普通 IPv4，避免内网判断失效。

**记录同步**：每条传输有唯一 id，两端按 id 合并、按 id 删除，不会产生重复条目。

**体积来源**：界面全部用 GDI+ / Canvas 自绘，没有 WebView、没有 UI 框架、没有图片资源，所以才能做到几百 KB。

## 从源码构建

> 仓库**不包含**工具链，需要自己准备。

### 工具链放哪里

两个构建脚本都会往上退两级定位工具链根目录，所以只要把 `gongj` 放在**仓库根目录**（和 `源码`、`tools` 同级）即可：

```
AirLink/
├─ 源码/
├─ tools/
└─ gongj/                     ← 自己新建
   ├─ w64devkit/bin/g++.exe   电脑端编译用
   └─ android/sdk/            手机端打包用（build-tools/35.0.0、platforms/android-35）
```

### 电脑端

```powershell
cd "源码\AirLink-Windows-源码"
powershell -ExecutionPolicy Bypass -File .\build.ps1
# 产物：out\AirLink.exe
```

依赖 `g++`（C++17）与 `windres`；静态链接，产物不依赖任何 DLL。

### 手机端

```powershell
cd "源码\AirLink-Android-源码"
powershell -ExecutionPolicy Bypass -File .\build.ps1
# 产物：out\AirLink.apk
```

需要 JDK 11+ 与 Android SDK 的 `aapt2`、`d8`、`zipalign`、`apksigner`。

两处需要按自己机器改：

- `build.ps1` 第 10 行的 `$env:JAVA_HOME`（当前写死为某个本地路径）
- 若 `build\airlink.jks` 不存在，脚本会用内置口令自动生成一个新签名密钥——**发布自己的版本前请换成自己的密钥和口令**

## 常见问题

**手机熄屏后电脑读不到文件？**
把「后台耗电管理」改成允许后台高耗电，并打开自启动、后台弹出界面。软件设置页里的「锁屏后保持连接」会显示最近一次保活是否成功。

**扫码没反应？**
先看扫描界面底部的帧计数：数字在涨说明相机正常，只是画面不够清晰——靠近一点、调亮屏幕；数字不动说明相机权限没给。

**WAN 连不上？**
① 确认两端都有公网 IPv6（电脑「WAN 连接」页能显示 IPv6 才算）；② 地址要带方括号和端口；③ Windows 防火墙要放行 TCP 45678；④ 配对码要一致。

**局域网里看不到对方？**
两端必须在同一个广播域（同一个路由器 / 同一个 Wi-Fi）。开了 AP 隔离，或者一个连 Wi-Fi、一个连到不同网段的有线口，都可能看不见。

## 已知限制

- 广域网依赖公网 IPv6；没有 IPv6 时会退回 UPnP，但部分路由器或 CGNAT 环境下可能失败
- 传输链路未加密（见「安全说明」）
- 界面为自绘，未做无障碍（TalkBack）适配
- 扫码识别率受显示器和拍摄距离影响，手输地址始终可用
